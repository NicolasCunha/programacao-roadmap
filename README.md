# Plano de Estudos: Do Zero ao Desenvolvedor Java

Este repositório organiza uma trilha de estudos para pessoas que estão começando do zero em programação e querem chegar em Java com uma base sólida.

A proposta é evoluir com calma:

1. Aprender lógica com VisuAlg.
2. Migrar para Java e orientação a objetos.
3. Estudar banco de dados, testes, Git, qualidade, padrões de projeto, Spring Boot e projeto final.
4. Praticar com folhas de exercícios separadas por tecnologia e dificuldade.

Não existe prazo fixo por etapa. O estudante deve avançar quando conseguir explicar, praticar e aplicar o conteúdo.

## Recomendação importante sobre uso de IA

Durante os estudos, evite usar IA para gerar o código final dos exercícios.

A IA pode ser útil para:

- Explicar um conceito com outras palavras.
- Dar exemplos conceituais.
- Ajudar a entender uma mensagem de erro.
- Sugerir caminhos de estudo.
- Criar exercícios adicionais.

Mas, no começo, não use IA para:

- Escrever o algoritmo por você.
- Resolver a folha de exercícios inteira.
- Gerar a classe Java pronta.
- Criar o SQL final sem você tentar antes.

O objetivo dos primeiros exercícios é fortalecer memória, raciocínio e familiaridade com padrões básicos. Se a IA escrever o código, o estudante pode entender a explicação, mas não fixa o processo de construção.

Uma boa regra é:

> Primeiro tente sozinho. Depois consulte anotações. Depois revise exemplos anteriores. Só então use IA para tirar dúvida pontual.

## Como estudar cada exercício

Para cada exercício, siga este ciclo:

1. Leia o enunciado inteiro.
2. Escreva a solução em passos, antes do código.
3. Faça uma primeira versão simples.
4. Execute.
5. Corrija erros.
6. Comente o que aprendeu.
7. Salve no GitHub.
